# 마냐나 × 뚜벅냥이

AIM 3차시 · 멕시코 팀 앱 프로토타입 (iPhone 18 Pro Max 440×956pt 기준)

- 비행기가 연착되거나 공항에서 오래 기다려야 할 때, 멕시코시티 공항을 본뜬 3D 지도에서 잘 곳·먹을 곳·쉴 곳을 찾아요.
- 시간이 남으면 공항 남쪽 출구로 나가 작은 동네에서 길고양이와 친구가 돼요. 고양이 수집 구조와 2D UI는 옆 팀 앱 "뚜벅냥이"에서 가져와 마냐나 디자인 시스템으로 다시 만들었어요.

**바로 보기:** https://hangnar.github.io/manana-airport/

## 조작
- 하단 조이스틱 또는 WASD · 방향키로 이동
- 가까이 가면 시설 아이콘이 나타나요 · 아이콘을 누르면 가격·위치·스페인어 문장
- 고양이 앞에서 "만나기" → 링이 금색 원에 닿을 때 "천천히 눈 깜빡이기"

## 파일
- `index.html` — 배포되는 한 장짜리 앱 (캐릭터 3D 모델이 안에 들어 있음)
- `src/nimodo-map.src.html` — 원본. 고친 뒤 `python3 src/build.py`로 다시 만들어요
- `src/mexico_bunny_3d.glb` — 팀 캐릭터(멕시코 토끼) 모델

지도와 가격은 예시이고, 기록은 보는 사람의 브라우저에만 저장돼요.
